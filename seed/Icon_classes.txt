== Pragma icon classes ==

These examples use the public <code>ubuntu-pragma-icon-<name></code> classes directly in wiki text. The icon classes are available on every page.

=== Inherited colour ===

<span style="color: var(--color-destructive);">This text and the <span class="ubuntu-pragma-icon-warning" aria-hidden="true"></span> warning icon use the same colour.</span>

=== Component usage ===
The Button template uses the same public class contract:

{{Button|text=Desktop|target=Category:Desktop|icon=desktop}}

{{Button|text=Server|target=Category:Server|icon=machines}}
